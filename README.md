# Portfolio Realms — Project Documentation

**Document date:** 2026-10-22  
**Project status:** Early learning/prototype, movement implemented; aiming attempted and a correction provided, not yet confirmed; combat not yet implemented.

Portfolio Realms is a browser-playable, dark-fantasy, 2D isometric action RPG inspired by Path of Exile 2, scaled down into a software-engineering portfolio experience. Visitors enter portals representing real projects or experience, explore short procedurally generated dungeons, fight a boss and reveal portfolio details as ancient scrolls. Visitors can also skip an individual dungeon or open the portfolio directly without playing.
